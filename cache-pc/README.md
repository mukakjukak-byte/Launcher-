# Кэш для ПК

Что лежит в этой папке, лаунчер раздаёт игрокам:

| Путь здесь | Куда попадёт у игрока |
|---|---|
| `UserFiles/...` | `Документы\GTA San Andreas User Files\...` (настройки SA-MP и игры) |
| всё остальное | папка игры (где `gta_sa.exe`): свои моды, `.asi`, текстуры, `models/` … |

Сейчас тут лёгкий кэш: `UserFiles/SAMP/sa-mp.cfg` — настройки SA-MP для слабых ПК
(лимит 50 FPS, 10 строк чата, без поворота головы, время в чате).

Выложить/обновить: **Actions → Publish cache → Run workflow → target: pc**.
Лаунчер скачает кэш при следующем нажатии «Играть», если версия поменялась.

Не клади сюда файлы самой GTA SA (gta3.img, gta_sa.exe и т.д.) — только своё.
