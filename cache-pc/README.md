# Кэш для ПК

Положи сюда файлы, которые лаунчер должен положить **в папку GTA San Andreas**
(в той же структуре: `models/`, `data/`, `SAMP/`, свои `.asi`, текстуры …).

Затем: **Actions → Publish cache → Run workflow → target: pc**.
Лаунчер при нажатии «Играть» сам скачает и распакует кэш, если версия поменялась.

Не клади сюда файлы самой GTA SA (gta3.img целиком, gta_sa.exe и т.д.) —
только свои модификации. Игра у игрока должна быть своя.
